# 情報システム部門向け：Careerbot Local Note の通信・データ仕様

## 概要

Careerbot Local Note は、職員PC上で動作するローカルWebアプリケーションです。
Pythonで書かれた小さなHTTPサーバーが `127.0.0.1:8765`（ループバックアドレス）で待ち受け、Google Chromeを操作画面として使います。
**他のPCやインターネットからは接続できず、相談内容を外部に送信する機能は存在しません。**

## 構成

```
[Chrome] ──127.0.0.1:8765──> [app.py（本ツール）]
                                  ├─ Whisper（文字起こし・同一プロセス内）
                                  └─127.0.0.1:11434──> [Ollama（LLM・同一PC）]
```

## 発生する通信

| 通信先 | タイミング | 内容 | 相談内容の含有 |
|---|---|---|---|
| pypi.org | 初回起動時 | Pythonライブラリの取得 | なし |
| huggingface.co | 初回の文字起こし時 | Whisperモデル（約1.5GB） | なし |
| ollama.com | `ollama pull` 実行時 | LLMモデル | なし |
| 127.0.0.1:11434 | 要約・話者推定時 | 文字起こしテキスト | **PC内のみ** |

上記以外の通信は発生しません。モデル取得後は、ネットワークを切断した状態でも全機能が動作します。
プロキシ環境では、初回のモデル取得のみプロキシ設定が必要です（`HTTPS_PROXY` 環境変数）。

## データの保存

| データ | 保存先 | 保持 |
|---|---|---|
| 録音音声 | `<データフォルダ>/<セッションID>/audio.webm` | 文字起こし完了後に即削除（既定） |
| 文字起こし | `<データフォルダ>/<セッションID>/session.json`, `transcript.md` | 利用者が削除するまで |
| 要約・振り返り | 同上 `summary.md`, `review.md` | 同上 |
| 利用ログ・テレメトリ | なし | — |

既定のデータフォルダはユーザーのホーム直下 `CareerbotLocalNote/` です。`config.py` または環境変数 `LOCAL_NOTE_DATA_DIR` で変更できます（暗号化ボリューム上のフォルダの指定も可能）。
ファイルはプレーンテキストです。暗号化は行わないため、PCのディスク暗号化（FileVault / BitLocker）とアカウントのパスワード保護を前提としています。

## 必要な権限

- Ollama のインストール（管理者権限が必要な場合があります）
- Python 3.10 以上のインストール
- Chrome のマイク使用許可（macOSはシステム設定のマイク許可も必要）
- 本ツール自体はユーザー領域で動作し、管理者権限・システム設定の変更は不要です

## 確認方法

ソースコードは全文公開されています。通信先を確認するには、`app.py` `llm.py` `transcriber.py` 内の `requests.` および `urllib` の呼び出しを検索してください。`127.0.0.1` 以外への送信は存在しません。
