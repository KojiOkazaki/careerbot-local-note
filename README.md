# Careerbot Local Note

大学キャリアセンターのカウンセラー向け、**完全ローカルの相談記録支援ツール**です。
面談を録音すると、このPCの中だけで文字起こし・話者推定（カウンセラー／学生）・相談記録の要約・カウンセリングの振り返りを作成します。

- 音声・文字起こし・相談記録は **外部に一切送信しません**（インターネット上のサーバーは使いません）
- 利用料・API料金は **かかりません**
- 無償・無保証・サポートなし（下記「利用条件」参照）

> **重要**：本ツールは無償で提供され、動作保証および個別サポートはありません。相談記録の保管・削除・管理の責任は、利用者および所属機関にあります。録音前に学生の同意を得てください。

## 動作環境

| | 推奨 | 最低 |
|---|---|---|
| OS | macOS（Apple Silicon） | macOS（Intel）／Windows 11（動作未確認） |
| メモリ | 16GB | 8GB |
| 空き容量 | 10GB | 6GB |
| ブラウザ | Google Chrome | |

8GBのPCでも動きますが、文字起こし・要約に時間がかかります（60分の面談で目安10〜20分）。

## セットアップ（初回のみ・15分程度）

1. **Ollama をインストール**：https://ollama.com からダウンロードしてインストール、起動しておく
2. **LLM を取得**：ターミナルで次を実行（メモリ8GBのPCは `gemma4:e2b`、16GB以上は `gemma4:e4b`）
   ```
   ollama pull gemma4:e4b
   ```
3. **Python 3.10 以上**を入れる：https://www.python.org/downloads/ （Macは `python3 --version` で確認）
4. **本ツールをダウンロード**：このページ右上の「Code」→「Download ZIP」→ 解凍して好きな場所に置く
5. **起動**：`start.command` をダブルクリック（初回はライブラリの取得で数分待ちます）
   - 「開発元を確認できないため開けません」と出たら、右クリック→「開く」
6. Chromeで `http://127.0.0.1:8765` が開きます。画面左の「準備の確認」がすべて ✓ になればOK
7. 初回の文字起こし時に、Whisperモデル（約1.5GB）が自動でダウンロードされます

2回目以降は `start.command` をダブルクリックするだけです。

## 使い方

1. マイクを選び、必要ならカウンセラー名を入れる
2. 学生に記録の同意を得て「録音を開始」
3. 面談後「録音を止めて文字起こし」→ 数分待つ
4. 「話者を推定」→ カウンセラー／学生のラベルが付きます（間違いはラベルをクリックして修正）
5. 「相談記録（要約）」タブ → 相談記録を作成
6. 「振り返り」タブ → 自分の面談の振り返りを作成
7. 「Markdownを保存」で書き出し、大学の相談記録システムに転記。不要になった記録は「この記録を削除」

ZoomやTeamsで録音した音声ファイル（m4a / mp3 / wav）を読み込んで文字起こしすることもできます。

## データの扱い

| データ | 保存場所 | 外部送信 |
|---|---|---|
| 録音音声 | 文字起こし直後に削除（`config.py` で変更可） | しない |
| 文字起こし・要約・振り返り | `~/CareerbotLocalNote/日時のフォルダ/` | しない |
| 利用状況・ログ | 収集しない | しない |

ネットワーク通信が発生するのは以下のみで、いずれも相談内容を含みません。
- Ollama によるLLMモデルの初回ダウンロード（ollama.com）
- Whisperモデルの初回ダウンロード（huggingface.co）
- 初回セットアップ時のPythonライブラリ取得（pypi.org）

情報システム部門向けの詳細は [docs/SECURITY.md](docs/SECURITY.md) を参照してください。

## よくあるトラブル

**「Ollama：接続できません」**
Ollamaが起動していません。アプリケーションからOllamaを起動してください（メニューバーにラマのアイコンが出ます）。

**「LLM：gemma4:e4b（未取得）」**
ターミナルで `ollama pull gemma4:e4b` を実行してください。別のモデルを使いたいときは `config.py` の `LLM_MODEL` を書き換えます。

**文字起こしがとても遅い**
`config.py` の `WHISPER_MODEL` を `"medium"` や `"small"` にすると速くなります（精度は下がります）。

**要約でエラーになる／途中で止まる**
メモリ不足の可能性があります。他のアプリを閉じるか、`LLM_MODEL = "gemma4:e2b"` に変更してください。

**マイクが使えない**
Chromeのアドレスバー左のアイコンからマイクを許可してください。Macは「システム設定 → プライバシーとセキュリティ → マイク」でChromeを許可します。

**話者推定が間違う**
内蔵マイク1本での推定には限界があります。面談の冒頭でカウンセラーが名乗る、画面でカウンセラー名を入れる、間違ったラベルはクリックで直す、の3つで実用的になります。

**大学PCで管理者権限がない**
Ollamaのインストールに管理者権限が必要な場合があります。情報システム部門に `docs/SECURITY.md` を添えて相談してください。
